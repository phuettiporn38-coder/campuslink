ยินดีต้อนรับสู่ CampusLink UP แพลตฟอร์มบริหารจัดการ กิจกรรม ข้อมูลการเข้าร่วม และระบบสะสมหน่วยกิต/ทรานสคริปต์กิจกรรมนิสิตระดับมหาวิทยาลัย ออกแบบมาเพื่ออำนวยความสะดวกต่อนิสิต คณาจารย์ และผู้จัดกิจกรรมในการสร้าง ลงทะเบียน เช็คอินผ่าน QR Code และประมวลผลทรานสคริปต์อัตโนมัติ

✨ ฟีเจอร์หลักของระบบ (Key Features)
👥 ระบบยืนยันตัวตนและบทบาท (Multi-Role Authentication):
นิสิต (Student): ลงทะเบียนกิจกรรม, สะสมชั่วโมงกิจกรรม, ดูทรานสคริปต์อิเล็กทรอนิกส์, สแกน QR Code เช็คอิน
ผู้จัดกิจกรรม/อาจารย์ (Organizer): สร้าง/แก้ไขกิจกรรม, กำหนดจำนวนที่นั่ง, ตรวจสอบรายชื่อ, สแกน QR เช็คอินผู้เข้าร่วม
ผู้ดูแลระบบ (Admin): อนุมัติกิจกรรม, ตรวจสอบความถูกต้องของระบบ และดูแดชบอร์ดสถิติภาพรวม
🎟️ ระบบลงทะเบียนและคิวสำรองอัตโนมัติ (Waitlist Engine):
เมื่อกิจกรรมเต็มจำนวนที่นั่ง (Max Participants) ระบบจะจัดให้ลงทะเบียนในสถานะ คิวสำรอง (WAITING) ทันที
ระบบเลื่อนคิวอัตโนมัติ (Auto-Promotion): เมื่อนิสิตตัวจริงกดยกเลิกสิทธิ์ ระบบจะเลื่อนคิวสำรองลำดับแรกขึ้นมาเป็นตัวจริง (CONFIRMED) โดยอัตโนมัติทันที
📱 ระบบเช็คอินด้วย QR Code & Token อัจฉริยะ:
สร้าง QR Code เฉพาะตัวสำหรับใบสมัครแต่ละใบ ป้องกันการเช็คอินซ้ำซ้อนหรือการสแกนปลอม
รองรับกล้องสแกน QR หน้างานและบันทึกเวลา checked_in_at แบบเรียลไทม์
📊 แดชบอร์ดวิเคราะห์และระบบส่งออกข้อมูล:
สรุปสถิติการเข้าร่วมกิจกรรมแยกตามหมวดหมู่ (วิชาการ, กีฬา, บำเพ็ญประโยชน์, ศิลปวัฒนธรรม)
ส่งออกข้อมูลและผังระบบ (Interactive System Flow & SVG Vector Export) สำหรับนำไปประกอบรายงานโครงงาน
🚀 วิธีการใช้งานระบบ (User Guide)
สำหรับนิสิต (Student Journey):
เข้าสู่ระบบ: เปิดลิงก์ https://campuslink-0qgd.onrender.com หรือเข้าสู่ระบบด้วยบัญชีทดสอบในระบบ
ค้นหาและลงทะเบียนกิจกรรม:
ไปที่แท็บ "ค้นหากิจกรรม" หรือหน้าแรกเพื่อเลือกกิจกรรมที่สนใจ
กดปุ่ม "ลงทะเบียนเข้าร่วม" (หากที่นั่งเต็ม ระบบจะบันทึกเป็นคิวสำรอง WAITING)
ตรวจสอบตั๋วและ QR Code:
ไปที่แท็บ "กิจกรรมของฉัน" เพื่อดู QR Code ส่วนตัวสำหรับใช้สแกนหน้างาน
เช็คอินและรับหน่วยกิต:
นำ QR Code ไปให้ผู้จัดงานสแกนหน้างานเพื่อบันทึกการเข้าร่วมและสะสมชั่วโมงใน ทรานสคริปต์กิจกรรม (Activity Transcript)
สำหรับผู้จัดกิจกรรม (Organizer Journey):
สร้างกิจกรรมใหม่:
เข้าสู่ระบบด้วยบัญชี Organizer (เช่น somchai.n@up.ac.th)
คลิกปุ่ม "สร้างกิจกรรมใหม่" ระบุชื่อ, รายละเอียด, วันเวลา, สถานที่ และจำนวนที่นั่งสูงสุด
จัดการผู้เข้าร่วมและเช็คอิน:
เปิดหน้ารายชื่อผู้สมัครของกิจกรรมเพื่อตรวจสอบสถานะ
ใช้ฟังก์ชัน "สแกน QR เช็คอินหน้างาน" เพื่อสแกนตั๋วของนิสิตและบันทึกเวลาเข้าร่วมทันที
